## Pattern
When a user worries that repetitive niche/regulated-sounding keywords (e.g. "concurso", "taxa", "Polícia Militar") in an ads-driven lead funnel risk an account flag, the fix is a full copy reframe around the same audience's *adjacent* pain point — not a cosmetic find-replace.

For this project: shifted from "concurso público / candidato / edital" language to "vida funcional do servidor público" (estágio probatório, Processo Administrativo Disciplinar, promoções/transferências, reintegração). Same legal practice area (Direito Administrativo) and same WhatsApp-lead funnel mechanics stayed intact — only the entry-point framing changed.

**Why:** repetitive high-risk-sounding vocabulary across headline, FAQ, stats panel, and disclaimer text is what trips ad-policy review, not the underlying practice area. Swapping to a later-career-stage angle keeps the same target audience and conversion intent addressable, while removing the risky vocabulary.

**How to apply:** when doing this kind of reframe, touch *every* surface that repeats the old vocabulary, not just the main landing page — shared header/footer chrome components, legal/privacy/terms pages linked from the footer, and SEO/JSON-LD metadata (title, description, keywords, OG tags, FAQPage schema) all need the same pass. It's easy to update the hero page and miss the shared chrome or the legal boilerplate pages, leaving inconsistent old wording live.
